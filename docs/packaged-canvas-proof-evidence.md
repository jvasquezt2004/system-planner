# Packaged Canvas & SVG Playback Proof Evidence

**Ticket:** [#117 — Prove the architecture canvas and SVG playback in packaged apps](https://github.com/jvasquezt2004/db-planner/issues/117)  
**Parent:** [#116 — System-design workspaces with linked schemas and animated Walkthroughs](https://github.com/jvasquezt2004/db-planner/issues/116)

## Verification scope

The packaged verifier launches the built desktop application and runs checks inside its rendered native WebView. The application reports the results to a loopback HTTP endpoint started by `scripts/verify-packaged-proof.ts`; the verifier fails on a missing report, missing required check, duplicate check, or failed check. Linux installation runs the package self-extractor before launching the installed `bin/launcher`, ensuring the proof uses the package just built. Windows runs the packaged `Schema Designer-Setup.exe` with no arguments (its `/S` and `--quiet` flags are rejected or treated as uninstall requests), stops it once its files are installed because its completion window otherwise waits for a click, and then launches the installed `app\bin\launcher.exe`.

The browser-side proof checks bundled fonts and network resources, component dragging and connected-path updates, deduplicated movement of a member in an overlapping Group, Service collapse/expand and focus, distinct parallel SVG paths, native SVG path sampling, playback seeking in both directions, play/pause, speed, parallel and retry walkthrough steps, reduced motion, and in-WebView SVG-to-PNG rasterization and image decoding.

## Observed Linux result

Local run: `bun scripts/verify-packaged-proof.ts` on Linux x86_64, under Xvfb, using the packaged Electrobun application and WebKitGTK.

- WebView user agent: `Mozilla/5.0 (X11; Linux x86_64) AppleWebKit/605.1.15 (KHTML, like Gecko) Version/60.5 Safari/605.1.15`.
- Viewport: 1440 × 900.
- Result: all 16 required checks passed.
- IBM Plex Sans Variable, IBM Plex Mono, and Newsreader Variable loaded; no external HTTP(S) assets were observed.
- Dragging `comp-api` moved its rendered bounds by 32 × 18 px and changed the connected SVG path while retaining endpoint IDs `comp-client` and `comp-api`.
- Dragging `grp-compliance` moved its member by exactly 28 × 14 px; ownership remained `svc-ingestion`.
- Service collapse/expand and focus checks passed; parallel connections had distinct paths; SVG `getTotalLength()` and `getPointAtLength()` returned finite samples.
- Seeking advanced to 4150 ms and then backward to 3113 ms; play/pause, 2× speed, parallel step, finite retry, and reduced-motion checks passed.
- In-WebView PNG decoded at 1140 × 610, 78,710 base64 payload bytes; SVG export carried embedded font styling.

The raw machine-readable report is `build/webview-proof-report.json` and is generated by each verifier run. CI uploads the report as a job artifact.

## Platform coverage and limits

The verifier has Linux and Windows branches. Linux was exercised locally as described above and in CI. Windows WebView2 was exercised in CI only; the Windows result above comes from that job, not from a local Windows run. CI report artifacts record the observed platform, WebView user agent, viewport, checks, and export measurements.

This finite proof covers the named interactions and export path in the packaged WebView. It is not a general performance benchmark, screenshot review, or proof of behavior on every supported OS/runtime version.
